# Aio-DeepSeek

[![Latest Build](https://img.shields.io/badge/version-0.1.0-blue)](package.json)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Chrome%20%7C%20Edge%20%7C%20Firefox-orange)]()

**Aio-DeepSeek** یک افزونه مرورگر فارسی‌محور برای تقویت رابط چت [DeepSeek](https://chat.deepseek.com) است؛ با پرامپت سیستمی مخفی، ابزارهای تخصصی، حافظه ماندگار، ساخت فایل و ارائه، و بسته‌بندی کارهای طولانی — همه به‌صورت محلی و خصوصی روی دستگاه خودتان.

> این پروژه یک فورک مستقل و بومی‌سازی‌شده برای کاربران فارسی‌زبان از پروژه متن‌باز [Better DeepSeek](https://github.com/EdgeTypE/better-deepseek) (اثر Çağrı DÜRÜ، مجوز MIT) است. «Aio-DeepSeek» هیچ وابستگی‌ای به سرورهای سازنده اصلی ندارد و به‌طور رسمی وابسته، مرتبط یا مورد تأیید DeepSeek یا DeepSeek AI نیست. تمام نام‌ها، لوگوها و برندها متعلق به مالکان آن‌هاست.

## ✨ امکانات

### 🧠 پرامپت سیستمی مخفی
یک پرامپت سیستمی سفارشی که رفتار DeepSeek را هدایت می‌کند بدون آن‌که در چت شلوغ شود. این پرامپت به‌طور خودکار به هر گفتگو تزریق می‌شود و از پنل تنظیمات افزونه قابل ویرایش است.

### 🏷️ تگ‌های ابزار برای خروجی‌های پیشرفته
Aio-DeepSeek مجموعه‌ای از تگ‌های ویژه را معرفی می‌کند که DeepSeek می‌تواند برای تولید محتوای غنی و تعاملی از آن‌ها استفاده کند:

- `<AIO:VISUALIZER>...</AIO:VISUALIZER>` – شبیه‌سازی‌های تعاملی و نمودارهای تک‌رنگ پرکنتراست با کیت رابط کاربری داخلی.
- `<AIO:create_file fileName="path/to/file.ext">...</AIO:create_file>` – تولید فایل قابل دانلود با نام و محتوای مشخص.
- `<AIO:pptx>...</AIO:pptx>` – تولید ارائه پاورپوینت با کتابخانه PptxGenJS.
- `<AIO:excel>...</AIO:excel>` – تولید فایل اکسل با SheetJS.
- `<AIO:docx>...</AIO:docx>` – تولید سند Word با کتابخانه docx.
- `<AIO:chart>...</AIO:chart>` – نمودارهای تعاملی با مشخصات Vega-Lite.
- `<AIO:AUTO:REQUEST_WEB_FETCH>url</AIO:AUTO:REQUEST_WEB_FETCH>` – دریافت خودکار صفحه وب و تبدیل به Markdown در کانتکست چت.
- `<AIO:AUTO:REQUEST_GITHUB_FETCH>owner/repo</AIO:AUTO:REQUEST_GITHUB_FETCH>` – دریافت خودکار مخزن گیت‌هاب و تزریق کدها به کانتکست.
- `<AIO:AUTO:CODE_RUNNER language="python|javascript|typescript|lua|ruby">code</AIO:AUTO:CODE_RUNNER>` – اجرای خودکار کد.
- `<AIO:memory_write>key: value, importance: always|called</AIO:memory_write>` – ذخیره حافظه ماندگار درباره کاربر.
- `<AIO:character_create name="..." usage="...">...</AIO:character_create>` – ساخت پرسونا برای نقش‌آفرینی.
- `<AIO:IMAGE>search query</AIO:IMAGE>` – نمایش تصویر مرتبط با درخواست.
- `<AIO:midi>...</AIO:midi>` – تولید موسیقی MIDI با نمادگذاری فشرده.

> سازگاری رو به عقب: گفتگوهای قدیمی ساخته‌شده با افزونه Better DeepSeek (تگ‌های `BDS:`) همچنان به‌درستی پردازش و پنهان‌سازی می‌شوند.

### 🔬 DeepCode (آزمایشی) و اتصال به DeepSeek Harness
حالت تعاملی برنامه‌ریزی و بازرسی کد:
- **برنامه‌ریزی تعاملی کد**: با فعال‌سازی DeepCode، مدل می‌تواند ساختار کدبیس را با ابزارهای خودکار (`FILE_READ`، `LIST_DIR`، `SEARCH_IN_DIRECTORY`) بررسی کند و طرح اجرای ساختاریافته تهیه کند.
- **تحویل به DeepSeek Harness**: پس از نهایی‌شدن طرح، وظایف به‌سادگی برای اجرای خودکار به [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) ارسال می‌شوند.

### 🔌 MCP (پروتکل کانتکست مدل)
اتصال به سرورهای MCP برای دسترسی به ابزارهای خارجی (جستجوی وب، APIها و...) مستقیماً از داخل چت با تگ `<AIO:AUTO:MCP>`.

### 📦 حالت پروژه LONG_WORK
کارهای طولانی و چندمرحله‌ای: مدل فایل‌های پروژه را مرحله‌به‌مرحله با `<AIO:create_file>` می‌سازد و افزونه در پایان همه را یک‌جا به‌صورت ZIP قابل دانلود بسته‌بندی می‌کند.

### 💾 حافظه ماندگار و مهارت‌ها
- **حافظه**: حقایق مهم درباره شما در بخش «حافظه ذخیره‌شده» نگه داشته می‌شود و به پرامپت‌های بعدی تزریق می‌گردد.
- **مهارت‌ها**: دستورالعمل‌های قابل استفاده مجدد (`.md` / `.json`) که با یک کلیک فعال می‌شوند.

### 🎙️ پشتیبانی صوتی (STT و TTS)
ورودی صوتی، پخش صوتی پاسخ‌ها و حالت زنده (Live Mode) برای گفتگوی صوتی دوطرفه. زبان گفتار قابل تنظیم است.

### 🌐 رابط کاربری
- **فارسی به‌صورت پیش‌فرض** — رابط کاملاً راست‌چین (RTL) با پشتیبانی هوشمند جهت متن (هر پاراگراف جهت خودش را تشخیص می‌دهد).
- زبان‌های دیگر: English، Русский، Türkçe، 简体中文 (از تنظیمات قابل تغییر است).
- ذخیره/خروجی گفتگو، کارت‌های پیشرفته برای فایل‌ها و نمودارها، حالت تاریک/روشن هماهنگ با سایت.

## 🚀 نصب

### نصب از سورس (روش فعلی)
1. مخزن را کلون کنید:
   ```bash
   git clone https://github.com/aio-deepseek/aio-deepseek.git
   cd aio-deepseek
   ```
2. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```
3. افزونه را بیلد کنید:
   ```bash
   npm run build
   ```
   این دستور پوشه‌های `dist-chrome` و `dist-firefox` را می‌سازد.
4. افزونه را در مرورگر بارگذاری کنید:

   **Chrome / Edge:**
   1. به `chrome://extensions` بروید.
   2. حالت «Developer mode» را فعال کنید.
   3. روی «Load unpacked» کلیک و پوشه `dist-chrome` را انتخاب کنید.

   **Firefox:**
   1. به `about:debugging` بروید.
   2. «This Firefox» → «Load Temporary Add-on».
   3. فایل ZIP داخل `dist-firefox` (یا پوشه بیلد) را انتخاب کنید.

   *توجه: بیلد Firefox آزمایشی است.*

## 📖 استفاده

پس از نصب، به [chat.deepseek.com](https://chat.deepseek.com) بروید. دکمه **AIO** را در گوشه بالا-راست می‌بینید؛ با کلیک روی آن پنل تنظیمات باز می‌شود.

### استفاده از تگ‌های ابزار
کافی است درخواستی بدهید که یکی از ابزارها به کار بیاید. چند نمونه:
- «یک اسکریپت پایتون که دنباله فیبوناچی را حساب کند بساز و اجرا کن.»
- «یک شبیه‌سازی تعاملی آونگ بساز.»
- «یک ارائه پاورپوینت درباره تغییرات اقلیمی تولید کن.»
- «یک اپ تو-دو کامل با ری‌اکت به‌صورت پروژه قابل دانلود بساز.»

DeepSeek به‌طور خودکار از تگ‌های مناسب استفاده می‌کند (راهنمایی‌شده توسط پرامپت تزریقی).

### مدیریت حافظه
وقتی DeepSeek با `<AIO:memory_write>` چیزی را ذخیره می‌کند، در بخش «حافظه ذخیره‌شده» پنل ظاهر می‌شود. خروجی/ورودی حافظه به‌صورت JSON هم ممکن است.

### آپلود پوشه و مخزن گیت‌هاب
روی دکمه «+» کنار ورودی چت کلیک کنید تا منوی آپلود پیشرفته باز شود. «Upload Folder» یک پوشه محلی را انتخاب و فایل‌های متنی آن را به یک آپلود یکپارچه تبدیل می‌کند. «GitHub Repo» مخزن را به‌صورت ZIP دریافت و به فایل متنی سبک (gitingest-style) تبدیل می‌کند.

برای مخزن‌های خصوصی، یک توکن دسترسی شخصی گیت‌هاب با دسترسی `repo` را در تنظیمات پیشرفته وارد کنید. توکن فقط به‌صورت محلی ذخیره می‌شود و تنها هنگام دریافت صریح یک مخزن به گیت‌هاب ارسال می‌شود.

## 🔒 حریم خصوصی و استقلال

- همه داده‌ها (حافظه، مهارت‌ها، تنظیمات) **به‌صورت محلی** در `chrome.storage.local` نگه‌داری می‌شوند.
- هیچ داده‌ای به سرورهای سازنده Aio-DeepSeek یا Better DeepSeek ارسال نمی‌شود (همگام‌سازی ریموت به‌طور کامل غیرفعال است).
- درخواست‌های شبکه فقط برای خودِ `chat.deepseek.com`، دریافت صفحات وب درخواستی شما، گیت‌هاب و صفحه رسمی قیمت DeepSeek انجام می‌شود.
- جزئیات بیشتر در [extension/PRIVACY.md](extension/PRIVACY.md).

## 🛠️ توسعه

```bash
npm run dev            # بیلد توسعه با watch
npm run build          # بیلد Chrome + Firefox
npm run test:unit      # تست‌های واحد (vitest)
npm run check-locales  # بررسی کامل بودن ترجمه‌ها
```

ساختار پوشه‌ها:
```
src/
├── content/     # اسکریپت محتوایی: پارسر تگ‌ها، UI (Svelte 5)، ابزارها
├── injected/    # اسکریپت MAIN-world: رهگیری payload و تزریق پرامپت
├── background/  # سرویس‌ورکر: منوی راست‌کلیک، پروکسی، آلارم‌ها
├── sandbox/     # محیط اجرای امن کد (eval sandbox)
├── lib/         # i18n، ثابت‌ها، ابزارهای مشترک
├── locales/     # فایل‌های ترجمه (fa پیش‌فرض)
└── styles/      # استایل‌های رابط
```
